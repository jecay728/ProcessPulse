# ProcessPulse

A browser-based manufacturing time-study workspace. The current MVP includes local video preview, editable process elements and timestamps, classifications, a visual cycle timeline, and CSV export.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Choose a video using **Upload video**; the file is previewed from a browser object URL and is not uploaded to a server. Video files are not persisted after the browser session.

## Current limitations

- Process-element suggestions are a UI placeholder and are not generated by an AI model yet. Suggested entries are drafts that need human review.
- Study metadata, persistence, authentication, and server-side video analysis are not implemented.
- Browser support and playback depend on the selected video's codec.
